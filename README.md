# **Iris Classifier  **  

This project is a machine learning-based Iris flower classifier built using Python, Django, and scikit-learn. The classifier predicts the species of an Iris flower (Setosa, Versicolor, or Virginica) based on the input features: sepal length, sepal width, petal length, and petal width.

## 🚀 Project Overview:
Model: A machine learning model trained on the famous Iris dataset using scikit-learn.

Framework: Django for the web application, allowing users to interact with the model via a simple web interface.

Deployment: The model is deployed and accessible via a user-friendly Django web app, which predicts the species of an Iris flower based on user input.

📊 Technologies Used:
Python

Django: Web framework for creating the web app.   

scikit-learn: For building and training the classification model.   

HTML/CSS/JavaScript: For building the front-end interface.    

SQLite: Database for storing user inputs and predictions (optional, depending on project setup).

🛠️ Features:     
Users can enter the four features (sepal length, sepal width, petal length, petal width) into a form.

The app predicts the Iris flower species (Setosa, Versicolor, or Virginica) using the trained model.

The prediction result is displayed on the same page after the user submits the form.
